# Read by Build/Scripts/sync_o3ds_core.py. The script starts from these
# headers, adds the .cpp next to each header, follows their #include lines,

# CRCpp's CRC.h (only while a core file includes it) from the pinned submodules.
#
# One path per line, relative to src/. Blank lines and '#' comments are
# ignored. List every core header that a plugin source file includes
# directly; the script fails if a plugin file includes an o3ds header that
# the closure does not contain. Headers reached only through other headers
# need no line.
