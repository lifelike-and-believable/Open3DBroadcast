# plugin root (forward slashes). '*' matches within one path segment, '**'
# matches any number of segments.
#
# Read by Build/Scripts/fab-package.py. The package-content assertions in
# that script run after these rules and fail the job if a debug symbol,
# script or developer document is still in the package, so a new file of
# that kind needs a rule here or a move out of the plugin.

# Debug symbols have no rule here on purpose (FAB-4, WP-F3): a committed .pdb
# must fail the job, not be silently left out. fab-package.py checks the
# tracked tree for them before any exclusion.
